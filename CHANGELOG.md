# Changelog

All notable changes to the Angels of Anonymity website will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-18

### Added
- Initial website launch
- Hero section with animated background and gradient blobs
- About section with highlights
- Team member cards with social links
- Expertise categories with skill lists
- Project portfolio with category filtering
- Project detail modal
- Experience timeline with years
- Competitions showcase section
- Contact section with multiple methods
- Statistics section with count-up animations
- Philosophy/quote section
- Fully responsive design (mobile-first)
- Smooth scrolling navigation
- Scroll reveal animations
- Hover effects and interactions
- Mobile menu with hamburger toggle
- Custom cursor effects (desktop)
- Easter egg (AOA key sequence)
- Navbar scroll effect with glassmorphism
- Performance optimization
- SEO optimization with meta tags
- Accessibility features
- Support for reduced motion preferences

### Features
- 100% static frontend - no build required
- Vanilla JavaScript (no frameworks)
- Configurable site settings
- Dynamic content from JavaScript data files
- Lazy image loading support
- Smooth transitions and animations
- Mobile-optimized interactions

### Documentation
- Comprehensive README.md
- CONTRIBUTING.md for contributors
- Inline code comments
- Configuration guide
- Deployment instructions

### Configuration Files
- .htaccess for server optimization

- .gitignore for version control
- package.json for dependencies
